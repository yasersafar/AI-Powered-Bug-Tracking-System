# Traceability: requirements → code → tests → status

Paths are relative to the repository root. Test names are the real test functions
(`backend/tests/`, `ml/tests/`, `extension/test/suite/`). Measured values are in
`docs/results/RESULTS.md`.

Status: **Met** (implemented and verified), **Implemented – target not met** (works, but a
measured target is missed; see the analysis), **Not met**, **Documented** (verified by
documentation or configuration rather than an automated test).
